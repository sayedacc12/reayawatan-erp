# اختبار الأداء مع البيانات الضخمة

أدوات لقياس سرعة سنابل عندما تكبر البيانات جدًا، وتُعاد بعد كل تطوير كبير للمقارنة.

> **تحذير:** تُشغَّل هذه الأدوات على نسخة اختبار معزولة فقط (جهاز المطور أو خادم اختبار).
> لا تُشغَّل أبدًا على خادم الإنتاج ولا على قاعدة بياناته، لأنها تضيف ملايين السجلات الوهمية.

## الخطوات

1. شغّل نسخة نظيفة من النظام (قاعدة بيانات فارغة) وأنشئ مدير منصة.
2. أنشئ 100 جمعية تجريبية كاملة (كل الأنظمة مترابطة، عبر خدمات النظام نفسها):

   ```bash
   bash loadtest/orgs.sh 100        # يحتاج متغيرَي ADMIN_LOGIN و ADMIN_PASSWORD
   ```

3. ضخّم بيانات جمعية واحدة لتصبح «جمعية كبيرة جدًا» (مئات الآلاف من المستفيدين والقيود):

   ```bash
   psql "$DATABASE_URL" -f loadtest/clone.sql
   psql "$DATABASE_URL" -v org=lt-001 -v k=1   -f loadtest/amplify.sql   # كبيرة جدًا
   psql "$DATABASE_URL" -v org=lt-002 -v k=0.1 -f loadtest/amplify.sql   # متوسطة
   ```

4. ابنِ قائمة الشاشات المقاسة (كل شاشات القراءة + صفحات التفاصيل بمعرّفات حقيقية):

   ```bash
   bash loadtest/build-routes.sh lt-001 > loadtest/routes.txt
   ```

5. قِس كل شاشة وكل تقرير، ثم حاكِ مستخدمين متزامنين:

   ```bash
   node loadtest/measure.mjs --org lt-001 --login <بريد مدير الجمعية> --password <كلمة المرور> \
     --routes loadtest/routes.txt \
     --reports beneficiaries,fundraising,projects,accounting,hr,governance,risk,volunteers,quality,audit,members,partnerships,knowledge,website,comms,meetings \
     --users 200 --seconds 60 --out loadtest/results/after.json
   ```

   النتيجة: زمن كل شاشة (الوسيط من 3 محاولات)، وعدد الشاشات التي تجاوزت ثانية،
   وزمن الاستجابة تحت الضغط (50% و95% و99% من الطلبات).

## المعايير

| الحكم | زمن الشاشة |
|---|---|
| ممتاز | أقل من 0.3 ثانية |
| مقبول | من 0.3 إلى ثانية واحدة |
| يحتاج إصلاحًا | أكثر من ثانية واحدة |

## المراقبة الدائمة في الإنتاج

شاشة **إدارة المنصة ← الأداء وحجم البيانات** تقيس الأداء الفعلي للمستخدمين الحقيقيين بلا أي أداة خارجية:
زمن كل شاشة، وحجم بيانات كل جمعية وكل نظام، مع قياس تلقائي يومي.
أول قياس يُحفظ «خط أساس» رسميًا، وكل قياس بعده يُقارن به. لا يتغير خط الأساس إلا بزر «اعتماده خط أساس».
